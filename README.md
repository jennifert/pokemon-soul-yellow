# Pokémon Soul Yellow

🚧 **This project is currently in development.**

Pokémon Soul Yellow is a personal Pokémon Yellow update project based on the `pret/pokeyellow` disassembly.

This repository contains the source code for the **Pokémon Soul Yellow companion website**. The site will provide detailed documentation for the patch, including changes from the original game and information useful while playing.

## Companion Site

Planned documentation includes:

* Pokédex, including updated movesets and evolution methods
* Wild Pokémon encounters by location
* Hidden items and other location information
* In-game trades
* TM and HM lists
* Gym Leader teams
* Elite Four and Champion teams
* Post-Champion rematches
* Important characters and NPCs
* Partner Pikachu changes and new interactions
* Gameplay and mechanical changes
* Shops, items, and evolution methods
* Patch information and release notes

The goal is to provide a reference guide similar in purpose to classic Pokémon game guide sites, while documenting the features and changes specific to Pokémon Soul Yellow.

## Team Builder

Pokémon Soul Yellow will use my existing Pokémon Team Builder rather than maintaining a separate version of the application.

The companion site will link to the builder with the Soul Yellow game database selected using:

`?game-id=soul-yellow`

This keeps the Team Builder as a shared project while allowing Pokémon Soul Yellow players to jump directly into the appropriate game data.

## Downloads

**Pokémon Soul Yellow does not distribute Pokémon Yellow ROM files or pre-patched ROMs.**

When releases become available, this project will provide **patch files only** through GitHub Releases.

Players are responsible for obtaining their own compatible copy of Pokémon Yellow and applying the patch themselves.
